🌙 SEED SLEEP ENTRIES

PoppyEngine · one-time setup

This writes the seven Sleep entries into the PoppyEngine editor's Firebase — the same place the editor saves to when you add an entry by hand. It does not touch PoppyEngine-core.js: that file is generated, so anything typed into it directly is lost on the next export.

Nothing else is modified. Entries are matched by name, so running this twice updates the seven rather than creating fourteen — and any edits you have since made to them in the editor are overwritten by the versions in this file. Your other entries are never read or changed.

After it finishes:

  1. Open PoppyEngine-Editor.html — the entries appear under a new Sleep & Rest category.
  2. Read them, adjust the wording to sound like you.
  3. Press Export PoppyEngine.js and paste the result over JS/poppy/PoppyEngine-core.js.

Poppy can't act on sleep until that export is pasted in — the engine is what unlocks the action field, and it only knows what the generated file tells it.
